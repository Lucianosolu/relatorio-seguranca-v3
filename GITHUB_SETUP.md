## 🆘 Problemas Comuns

### **❌ "Repository not found"**
- **Causa**: Repositório não existe no GitHub
- **Solução**: Crie o repositório manualmente primeiro

### **❌ "Permission denied"**
- **Causa**: Sem permissão no repositório
- **Solução**: Verifique se está logado corretamente

### **❌ "Nothing to push"**
- **Causa**: Tudo já está sincronizado
- **Solução**: Use `git status` para verificar
